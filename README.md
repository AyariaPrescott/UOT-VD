# 寰宇观游//虚拟神明

Rain World 自定义神经元猫，依赖 SlugBase。

当前发布版本：**0.2.0**。本次按用户明确授权发布已闭合的 0.2.0 快照；后续新功能不在本提交中。以后的推送仍须用户明确要求。

## 用户设定

- 角色名原样使用 **寰宇观游//虚拟神明**。
- 头顶漂浮一个与仰望皓月或五块卵石的神经元相似的**不朽神经元**，呈彩色渐变。
- 蛞蝓猫身体呈白色半透明，如电子幽灵，偶尔出现故障艺术色块。
- 不添加其他设定；完成度由用户在游戏中验证。

本轮用户反馈明确要求：神经元的彩色渐变要动态，漂浮不能像固定在头上；故障允许适当的身体部分错位和大块彩色方块；身体需要更透明。

## 实现说明

以下数值与方式是 Codex 的实现选择，不是用户补充设定，可按实际验收调整：

- 身体使用原版轮廓，不透明度从 45% 降为原版当帧值的 **16%**；保留原版眼睛颜色，并同步降低不透明度。
- 神经元继续使用原版 `OracleSwarmer` 的四个可见图形元素；改为有独立位置和速度的惯性漂浮，并在猫头上方游动、摆向、翻转。触须方向滞后于主体方向，参照原版神经元的绘制方式。
- 彩色渐变同时覆盖神经元表面并随时间流动，一轮约 4 秒；不再使用原来较慢的 24 秒循环。
- 故障短暂出现约 14–23 个游戏更新帧，加入 8–18 像素的大块彩色方块和横向色条；头部与眼睛、躯干、髋部与腿、尾巴可分别发生 2–7 像素的横向视觉错位。
- 错位仅改变当帧绘图。下次绘制前先恢复原始图形位置和尾巴网格，不累积偏移，也不改变实际位置、速度和碰撞。
- 神经元运动按游戏更新帧推进，多摄像机共享同一份运动状态；换房间和长距离转移会重置视觉跟随位置。
- 不朽神经元作为随角色绘制的外观存在，不生成可抓取、可食用的实体。“不朽”未被自行扩展为免死或其他能力。
- 角色行为和世界以 SlugBase 默认的生存者为基础；未设置额外数值、技能、剧情、地图、光源、粒子或声音。
- 没有为角色另画选角立绘；菜单可能显示空白立绘区域，角色名仍可用于选择。

## 安装与验证

1. 退出游戏，将 `dist/UniverseVoyager-0.2.0.zip` 中的 `universevoyager` 文件夹解压到游戏的 `RainWorld_Data/StreamingAssets/mods/`，覆盖旧版本的同名文件夹。
2. 在 Remix 中启用 SlugBase 和 **寰宇观游//虚拟神明**，按游戏提示应用并重启。
3. 在故事模式选择 **寰宇观游//虚拟神明**。
4. 静止观察神经元表面的颜色是否持续流动、神经元是否自行游动和转向；左右移动后停下，检查是否有惯性跟随。
5. 在有背景细节的地方检查身体是否明显更透明；等待故障，观察大方块、色条以及局部错位，故障结束后身体应恢复。
6. 行走、爬杆、钻管道和切换房间，检查外观是否正常跟随；其他角色应保持原貌。

游戏内完成度由用户验收。离线检查与编译通过并不代表已完成游戏内视觉验证。

## 重新构建

在 Windows PowerShell 中运行：

```powershell
& 'D:\UOT-VD\build.ps1' -GamePath 'D:\SteamLibrary\steamapps\common\Rain World'
```

需要 Windows 的 C# 编译器、.NET Framework 4.8 引用程序集，以及游戏自带的 BepInEx、HOOKS 和 Unity 程序集。构建脚本使用本机依赖，不下载或打包游戏程序集。输出位于 `mod/newest/plugins/` 和 `dist/`。
